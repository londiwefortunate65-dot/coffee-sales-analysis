# Coffee Sales Analysis — MySQL & Tableau

## Project Overview
This project analyzes coffee sales data using MySQL for data analysis and Tableau for data visualization. The goal is to identify sales trends, customer purchasing patterns, popular coffee products, and revenue performance.

## Tools Used
- MySQL Workbench
- SQL
- Tableau

## Analysis
- Monthly customer activity and trends across 2023, 2024, and 2025
- Sales performance by coffee type
- Customer purchasing patterns by weekday and hour
- Revenue and cost analysis

## Skills Demonstrated
- SQL querying and data aggregation
- Data analysis using MySQL
- Data visualization using Tableau
- Business insights and reporting

## Project Goal
To turn coffee sales data into meaningful insights that can support business decisions and improve understanding of sales performance.
